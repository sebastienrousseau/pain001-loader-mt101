# pain001-loader-mt101 v0.0.74

## Highlights ⭐️

* **In lockstep with pain001 0.0.74**: the family converges on one version again, and this package now requires `pain001 >= 0.0.74, < 1`.
* **Impossible dates are refused**: a `:30:` requested execution date such as `000000` or `260230` used to become `2000-00-00` or `2026-02-30`; it now raises a `ValueError` naming `:30:`.
* **Amounts must be in the SWIFT form**: `EUR1.234` used to be read as 1.234 and 400 nines as an infinite amount. A `:32B:` amount is now digits with at most one decimal comma, 15 characters at most, and anything else raises a `ValueError` naming `:32B:`.
* **Pinned and audited CI**: every CI install is hash-pinned and audited with `pip-audit`, the parser is fuzzed with Atheris and Hypothesis, and complexity is held to the family ceilings.
