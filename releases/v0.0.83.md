# pain001-loader-mt101 v0.0.83

## Highlights ⭐️

* **In lockstep with pain001 0.0.83**: this package requires `pain001 >= 0.0.83, < 1`. The core can now verify XML signatures against the signer's certificate with `pain001 verify-signature`.
* **Nothing in the loader changed**: the parser and its records are the same as in 0.0.82, and the pain.001.001.09 the core writes from them is unchanged. Upgrade it together with the core.

## Details

Every requirement file that pins `pain001` was regenerated; only `pain001` moved, and its hashes match the wheel and sdist on the core's v0.0.83 release.
