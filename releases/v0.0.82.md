# pain001-loader-mt101 v0.0.82

## Highlights ⭐️

* **In lockstep with pain001 0.0.82**: this package requires `pain001 >= 0.0.82, < 1`. The core can now check pain.001 files you already have with `pain001 check`.
* **Nothing in the loader changed**: the parser and its records are the same as in 0.0.81, and the pain.001.001.09 the core writes from them is unchanged. Upgrade it together with the core.

## Details

Every requirement file that pins `pain001` was regenerated, and the development tools ruff, filelock and hypothesis moved to their latest patch releases. If you add the columns pain.001.001.04 to .08 need and render one of those versions, the core now writes the default `service_level_code="SEPA"` as `PmtTpInf/SvcLvl/Cd` there as well.
