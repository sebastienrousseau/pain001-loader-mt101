# pain001-loader-mt101 v0.0.79

## Highlights ⭐️

* **In lockstep with pain001 0.0.79**: this package requires `pain001 >= 0.0.79, < 1`. The parser is unchanged.
* **The release page is written by the workflow**: a last `release-notes` job sets the title to `pain001-loader-mt101 0.0.79` and composes the body from this note, the pull requests merged since 0.0.78 and the SHA-256 of every attached asset. The 0.0.77 and 0.0.78 pages were rewritten by hand.
* **A missing note fails the pull request**: `tests/test_release_notes.py` fails once the CHANGELOG dates a version whose `releases/vX.Y.Z.md` is missing or has other than 2 to 4 highlights.

## Details

`scripts/release_notes.py` and `tests/test_release_notes.py` are vendored byte-identical from pain001. No runtime dependency other than the `pain001` floor changed since 0.0.78.
