# pain001-loader-mt101 v0.0.80

## Highlights ⭐️

* **In lockstep with pain001 0.0.80**: this package requires `pain001 >= 0.0.80, < 1`. pain001 0.0.80 is a security release of the core's REST API ([GHSA-vv3x-jpvc-w468](https://github.com/sebastienrousseau/pain001/security/advisories/GHSA-vv3x-jpvc-w468)).
* **Nothing in the loader changed**: the parser and its output are the same as in 0.0.79. Upgrade it together with the core.

## Details

This release moves only the version and the `pain001` floor. Every requirement file that pins `pain001` was regenerated, and no other dependency moved since 0.0.79.
