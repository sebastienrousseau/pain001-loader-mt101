# pain001-loader-mt101 v0.0.87

## Highlights ⭐️

* **In lockstep with pain001 0.0.87**: the MT101 parser and the records it hands to pain001 are the same as in 0.0.86. It now requires pain001 0.0.87.
* **Suite Consistency runs on schedule and dispatch only**: the workflow no longer starts on another workflow's completion (`workflow_run`), a trigger that runs with the default branch's trust whatever started it.
* **The daily ecosystem audit is green again**: it pins the core's check at a commit that knows the five pain001 SDK repositories, so the scheduled run no longer fails on them as undeclared members.
* **OpenSSF Best Practices badge in the README**: the Security section names the project's passing badge.

## Details

pyproject.toml, `__version__`, CITATION.cff, the README and the SECURITY.md and SUPPORT.md tables move to 0.0.87 together, as `scripts/verify_versions.py` requires.
