# pain001-loader-mt101 v0.0.89

## Highlights ⭐️

* **In lockstep with pain001 0.0.89**: the MT101 parser and the records it hands to pain001 are the same as in 0.0.88. It now requires pain001 0.0.89.
* **The docs set compiles again**: `make pip-compile` resolves the documentation requirements at Python 3.11.5, the oldest version soupsieve 4 supports, and stops on the first failure instead of leaving a stale lock file behind.
* **complexipy 9 in the complexity gate**: the ratchet's compare step is split in two so it stays under the cognitive ceiling of 15 that complexipy 9 measures, with the same report.
* **Dependabot updates folded in**: myst-parser 5.2.0, mdit-py-plugins 0.7.0, filelock 4.2.10, ruff 0.17.5, codespell 2.4.3 and hypothesis 6.170.15 in the hash-pinned development sets. The published package depends only on pain001.

## Details

pyproject.toml, `__version__`, CITATION.cff, the README and the SECURITY.md and SUPPORT.md tables move to 0.0.89 together, as `scripts/verify_versions.py` requires.
