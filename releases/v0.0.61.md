# pain001-loader-mt101 v0.0.61

Suite release with `pain001` 0.0.61. No change in this package.

The core's 0.0.61 is a performance release: XSD validation via libxml2
when `lxml` is installed, and a fix for a quadratic in CSV diagnostics.
Neither touches the MT101 parser, which does its own parsing and goes
through neither path — so this package is byte-for-byte what 0.0.60 was.

The version moves because every member of the `pain001` suite ships the
same number. See `pain001.suite`, which a daily job checks against PyPI.

## Compatibility

No API change. The public surface remains a single function:

```python
from pain001_loader_mt101 import parse_mt101

rows = parse_mt101(swift_message_text)
```

`pain001 >= 0.0.55, < 1` is unchanged; nothing here needs a newer core.
