# pain001-loader-mt101 v0.0.81

## Highlights ⭐️

* **In lockstep with pain001 0.0.81**: this package requires `pain001 >= 0.0.81, < 1`. In 0.0.81 the core checks every IBAN and BIC and refuses rows that mix payment batches, including rows this loader returns.
* **Nothing in the loader changed**: the parser and its output are the same as in 0.0.80. Upgrade it together with the core.

## Details

This release moves only the version and the `pain001` floor. Every requirement file that pins `pain001` was regenerated, and no other dependency moved since 0.0.80.
